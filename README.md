# kim-hammar.com

## Local preview

```
script/serve.sh
```

This serves the site at http://localhost:4000 with livereload. The script uses Homebrew's `ruby@3.4`, so install it first if you don't have it (`brew install ruby@3.4`). On the first run it installs the gems into `vendor/bundle`.

Pushing to `master` deploys the site through GitHub Pages.
