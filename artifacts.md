### 2026

[\[Causal Controlled Degradation (CCD)\]](https://github.com/Kim-Hammar/ccd) A Python library for cyber resilience through controlled degradation. [Data repository](https://huggingface.co/datasets/kimhammar/ccd).

[\[A multiagent incident response system\]](https://github.com/Kim-Hammar/multiagent-incident-response) A multiagent incident response system that autonomously investigates security incidents and recommends optimized response actions. [Video demonstration](https://www.youtube.com/watch?v=YXYk_5GCqUI).

[\[5G Cloud RAN measurements\]](https://huggingface.co/datasets/kimhammar/5G_measurements) A novel dataset comprising 168 hours of monitoring data collected from our 5G testbed.

### 2025

[\[SAB.jl\]](https://github.com/Kim-Hammar/SAB.jl) A Julia package implementing an aggregation method for value approximation of one-sided partially observed stochastic games (OS-POSGs); artifacts related to the paper "Scalable Solutions to Zero-Sum Partially Observable Stochastic Games Through Belief Aggregation with Approximation Guarantees", published at AAAI 2026.

[\[Code and data for incident response LLM fine-tuning\]](https://github.com/Kim-Hammar/llm_incident_response_ndss26) Artifacts related to the paper "Incident Response Planning Using a Lightweight Large Language Model with Reduced Hallucination", published at [The Network and Distributed System Security (NDSS) Symposium 2026](https://www.ndss-symposium.org/ndss-paper/incident-response-planning-using-a-lightweight-large-language-model-with-reduced-hallucination/). We introduce a novel method that enables the effective use of a large language model (LLM) to provide decision support for incident response planning. [Data repository](https://huggingface.co/datasets/kimhammar/CSLE-IncidentResponse-V1); [Video demonstration](https://www.youtube.com/watch?v=XXo4Y6LCWk4).

### 2021

[\[awesome-rl-for-cybersecurity\]](https://github.com/Kim-Hammar/awesome-rl-for-cybersecurity) A curated list of resources dedicated to reinforcement learning applied to cyber security.

[\[gym-optimal-intrusion-response\]](https://github.com/Kim-Hammar/gym-optimal-intrusion-response) A reinforcement learning environment for simulating attack and defense operations in an optimal stopping game.

### 2020

[\[The Cyber Security Learning Environment (CSLE)\]](https://github.com/Kim-Hammar/csle) CSLE is a framework for evaluating and developing reinforcement learning agents for control problems in cyber security. Everything from network emulation, to simulation, and learning in CSLE have been co-designed to provide an environment where it is possible to train and evaluate reinforcement learning agents for practical cyber security tasks. [Documentation](https://kim-hammar.github.io/csle/).

[\[gym-idsgame\]](https://github.com/Kim-Hammar/gym-idsgame) A reinforcement learning environment for simulating attack and defense operations in an abstract network intrusion Markov game.

### 2018

[\[Hopsworks\]](https://github.com/logicalclocks/hopsworks) Hopsworks is a platform for horizontally scalable deep learning pipelines on top of Hadoop. [Blog](https://www.logicalclocks.com/blog/introducing-hopsworks).

[\[FastTextOnSpark\]](https://github.com/Kim-Hammar/FastTextOnSpark) An implementation of the FastText algorithm for training word embeddings that runs on Spark, the first distributed implementation in the world.

[\[SemWebTutorial\]](https://github.com/Kim-Hammar/SemWeb_Tutorial) Semantic Web Tutorial. [Report](/assets/papers/2018/semweb_report.pdf).

### 2017

[\[Hops-util-py\]](https://github.com/logicalclocks/hops-util-py) A python library for deep learning and data processing.

[\[MLFD\]](https://github.com/Kim-Hammar/mlfd_prototype) Implementation of a next-generation failure detector for distributed systems with provable strong completeness, using a machine learning model updated with streaming data to detect machine failures. [Report](/assets/papers/2017/mlfd_report.pdf).

[\[FashionRec\]](https://github.com/shatha2014/FashionRec) Implementation in Tensorflow of a multi-class multi-label text classification model using probabilistic labels learned from weak supervision and support for pre-trained word embeddings.

[\[Erlang Pengine\]](https://github.com/Kim-Hammar/erl_pengine) A distributed erlang client to a prolog pengine server. It enables you to run first-order logic programs and constraint programming programs from Erlang.

[\[Distributed Linearizable Key-Value Store\]](https://github.com/Kim-Hammar/Distributed-KV-store) Implementation of a provable linearizable key-value store using virtually synchronous group communication and passive replication. [Report](/assets/papers/2017/kv_store_report.pdf).

[\[Logoot-Undo4J\]](https://github.com/Kim-Hammar/KompicsLogoot) Java implementation of CRDT for Logoot-Undo: Distributed Collaborative Editing System on P2P networks. [Report](/assets/papers/2017/crdt_report.pdf).

[\[Advent Of Code 2016 in Prolog\]](https://github.com/Kim-Hammar/Advent-Of-Code16-Prolog) Implementation of the Advent of Code series of challenges year 2016 in Prolog.

[\[DataMining\]](https://github.com/Kim-Hammar/DataMining) Implementation of various data mining algorithms. [Report](/assets/papers/2017/data_mining_report.pdf).

### 2016

[\[SSL VPN\]](https://github.com/Kim-Hammar/Basic_SSL_VPN) A C implementation of a SSL VPN that supports secure key exchange and encrypted communication.

[\[AgentProgramming\]](https://github.com/Kim-Hammar/AgentProgramming) Programming of Multi-Agent Systems. [Report 1](/assets/papers/2016/agent_programming_report_1.pdf); [report 2](/assets/papers/2016/agent_programming_report_2.pdf).
